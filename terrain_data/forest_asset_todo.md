# Forest prop backlog

The current library is sufficient for the main stylized forest passes. It does not contain dedicated fallen-log, stump, exposed-root, or loose-branch meshes.

## Add later

- 2-4 fallen logs with distinct silhouettes and a low collision profile.
- 2-3 tree stumps, including one mossy variant.
- 2 root clusters and 2 small loose-branch meshes.
- Optional leaf-litter cards or small decal meshes for close-up forest-floor variation.

Do not replace the existing tree library for these props. They are environmental-detail assets, not a blocker for the current forest biome.
