# NuuMon Godot Island

Godot 4.7.1 project using Terrain3D 1.0.2.

## Open and run

1. Clone this repository.
2. Open `project.godot` in Godot.
3. Run the project (`F6`/`F5`). The default scene is `scenes/world/world_island.tscn`.

The editable Terrain3D regions, biome materials, generated terrain texture
maps, ocean, lighting, and saved MultiMesh environment are in `terrain_data/`
and `scenes/world/`.

`.godot/` is intentionally ignored and will be regenerated by each machine.
The original `asset/terrain_textures/` archive and duplicate Ultimate source
folders are also ignored; the runtime-ready maps are already packed under
`terrain_data/biome_textures/`, and the GLTF assets used by the scene are kept
under `asset/`.
